# Images

The site uses **no photography and no screenshots**. The case studies are text,
data and CSS-drawn diagrams, so there is nothing here to produce or replace.

These five files are the entire image set, and they are already built:

| File | What it is |
|---|---|
| `og-default.jpg` | Link preview card for Home, Work, Services, About, Contact |
| `og-ttusa.jpg` | Link preview card for the Table Tennis USA case study |
| `og-gewo.jpg` | Link preview card for the GEWO USA case study |
| `og-paul.jpg` | Link preview card for the Paul David case study |
| `favicon.svg` | Browser tab icon |

## Why the preview cards matter

They are what appears when you paste a link into an email, a message, LinkedIn or
X. A link with a proper preview card gets opened noticeably more often than a bare
URL — which matters a great deal when the site's main job is cold outreach.

Each card is 1200 × 630, dark with the orange accent, carrying the AKINTAYO
wordmark and the page's headline. The Table Tennis USA card shows
`0.72% → 1.26% → 1.56%` along the bottom, so the number is visible before anyone
clicks.

## If you ever want to change one

They were generated by rendering an HTML template to PNG. To edit one by hand,
any 1200 × 630 JPG saved under the same filename will replace it — keep the dark
background and the orange accent so the set stays consistent.
